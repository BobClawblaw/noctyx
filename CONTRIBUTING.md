# Contributing

Thanks for helping. One thing before your first pull request:

1. **No private information.** No real host names, addresses, user names or paths from your own
   systems in code, tests, docs or commit messages — use `head`, `gpu-01`, `nas` and 192.0.2.0/24.
   `python3 tools/privacy_check.py` runs in CI and locally.

Contributions are licensed under Apache 2.0 automatically (see the license's terms); no separate
agreement is needed.

Run the tests with `python3 -m pytest`.
